# PPTX 디자인 가이드

이 저장소의 문서는 기본적으로 Markdown(`.md`)으로 작성합니다. 발표/공유 목적으로 **별도 요청이 있을 때만** 이 가이드의 디자인을 적용해 `.pptx`로 제작합니다.

## 컬러 팔레트

시그니처 컬러(블루-퍼플 계열)를 포인트로, 바탕은 흰색/회색을 사용합니다.

| 용도 | 색상명 | HEX |
| --- | --- | --- |
| 포인트(Primary) | 블루퍼플 | `#5B4FE0` |
| 포인트 강조(Primary Dark) | 딥 블루퍼플 | `#3730A3` |
| 포인트 연한 배경(Primary Light) | 라벤더 틴트 | `#EEF0FF` |
| 배경(기본) | 화이트 | `#FFFFFF` |
| 배경(보조/구분) | 라이트 그레이 | `#F5F6FA` |
| 본문 텍스트 | 다크 그레이 | `#1F2430` |
| 보조 텍스트 | 미드 그레이 | `#6B7280` |

- 포인트 컬러(`#5B4FE0`)는 제목, 강조 도형, 아이콘, 그래프 주요 시리즈 등 "시선을 끌어야 하는 요소"에만 사용합니다.
- 텍스트가 포인트 컬러 위에 올라갈 땐 흰색(`#FFFFFF`)을 사용하고, 흰/회색 배경 위 텍스트는 다크 그레이(`#1F2430`)를 사용합니다.
- 그래프/표에서 시리즈가 여러 개 필요하면 포인트 컬러를 기준으로 명도를 조절한 톤온톤(예: `#5B4FE0`, `#8B7FF0`, `#3730A3`)을 우선 사용하고, 부족하면 중립 그레이를 보조로 섞습니다.

## 폰트

- 한글/영문 본문: **Pretendard** (Regular/Medium/Bold) — 무료 라이선스, 가독성 좋은 국문 폰트
- 제목/강조: **Pretendard ExtraBold** 또는 **Pretendard Black**
- 시스템에 Pretendard가 없을 경우 대체: **Noto Sans KR**

## 슬라이드 구조

| 슬라이드 유형 | 배경 | 구성 |
| --- | --- | --- |
| 표지 | 화이트 | 좌상단 또는 하단에 포인트 컬러 도형 포인트, 큰 제목(ExtraBold) + 부제/날짜(그레이, 작게) |
| 섹션 구분 | 포인트 컬러(`#5B4FE0`) 풀 배경 | 흰색 텍스트로 섹션 번호 + 섹션 제목만 크게 |
| 본문(콘텐츠) | 화이트 | 상단에 얇은 포인트 컬러 바 + 제목, 본문은 텍스트/표/이미지. 강조 박스는 라벤더 틴트(`#EEF0FF`) 배경 사용 |
| 마무리 | 화이트 (표지와 통일감) | 감사 인사, 연락처/링크 |

- 비율은 16:9 기본.
- 슬라이드당 핵심 메시지 1개, 텍스트는 최소화하고 표/다이어그램으로 정리하는 것을 우선합니다.

## 생성 방식

- `.pptx` 생성은 `python-pptx` 라이브러리 사용을 기본으로 합니다. 작업 시 환경에 설치되어 있는지 먼저 확인하고, 없으면 설치 후 진행합니다.
- 원본 내용(뼈대)은 항상 같은 이름의 `.md` 문서로 먼저 작성/유지하고, `.pptx`는 그 내용을 이 가이드의 디자인으로 옮긴 산출물로 취급합니다 (즉 `.pptx`가 원본이 되지 않도록 함).
