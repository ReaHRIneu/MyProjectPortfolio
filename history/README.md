# 작업 기록 (History)

작업 세션마다 진행한 내용을 날짜순으로 기록하는 공간입니다. 월별로 파일을 분리합니다.

## 규칙

- 파일명은 `YYYY-MM.md` 형태로 짓습니다 (예: `2026-08.md`).
- 각 파일 안에서는 `## YYYY-MM-DD` 날짜 섹션 아래에 그날 진행한 작업을 불릿으로 기록합니다.
- 해당 월 파일이 없으면 새로 만들고 이 목록에 추가합니다.

## 참고

- [`next-session.md`](./next-session.md)는 다음 세션 시작 시 참고할 임시 작업 메모입니다. 위 월별 기록과 달리 매번 최신 상태로 덮어쓰는 파일이라 이 목록에는 포함하지 않습니다.
