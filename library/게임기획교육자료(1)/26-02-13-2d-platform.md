# 게임 개발 기초 상식 | 2D 플랫폼의 이해

2D 게임 세계를 구성하는 핵심 개념과 기술을 배워봅시다.

- 좌표

## 2D 세계의 구성

평면 위에서 펼쳐지는 게임 세계는 여러 시각적 요소들이 층층이 쌓여 만들어진다. 레이어, 스프라이트, 타일 등의 구성 요소를 이해하면 효율적인 2D 게임을 설계할 수 있다.

## Bitmap과 Vector

### Bitmap (비트맵)

화면을 점(Pixel) 단위로 표현하며, 각 픽셀마다 색상 정보(aRGB)를 저장하는 방식이다.

- jpg, gif, png, bmp, dds 등의 포맷
- 2D 게임에서 가장 널리 사용
- 확대 시 품질이 저하될 수 있음

### Vector (벡터)

좌표(Point)와 좌표 간의 연결을 수학적으로 연산하여 표현하는 방식이다

- 확대 축소가 자유로움
- 용량 변화가 거의 없음
- 로고, UI 등에 적합

## 레이어

2D 이미지를 투명한 필름처럼 여러 겹으로 쌓아올린 구조

### 레이어 구성의 목적

- UI 요소의 독립적 표시
- 게임 세계의 깊이감 구현
- 이펙트와 특수 효과 분리
- 이미지 재활용으로 용량 절약

## 레이어 분해 예시

### 고전 게임 분석

Street Fighter 2의 Ken 스테이지를 레이어별로 분해하면 배경, 구조물, 캐릭터가 각각 독립된 층으로 구성되어 있음을 알 수 있다. 이러한 분리는 애니메이션 처리와 충돌 감지를 효율적으로 만들어준다.

## 레이어 구성 순서

1. **원경 (Background)**: 가장 뒤쪽의 배경 이미지
2. **근경 (Foreground)**: 중간 거리의 배경 요소
3. **지형 (Ground)**: 플레이어가 서 있는 땅
4. **고정 오브젝트**: 구조물 등 움직이지 않는 요소
5. **유동 오브젝트**: 캐릭터, 몬스터, 아이템
6. **이펙트**: 각종 시각 효과
7. **환경 효과**: 날씨, 시간 표시
8. **커서 및 UI**: 가장 앞쪽의 인터페이스

## *동적*으로 변화하는 레이어

- **생성과 소멸**: 특정 상황에서만 나타나거나 사라지는 레이어가 있다.
- **순서 변경**: 캐릭터의 위치에 따라 앞뒤 순서가 동적으로 바뀐다.
- **시각 효과**: 반투명, 흑백 등의 효과가 상황에 따라 적용된다.

동적 = 실시간 변화

## 맵 / 배경

실제 게임 플레이가 이루어지는 배경

- **타일맵의 효율성**: RPG, RTS, 시뮬레이션 등 많은 장르에서 효율성을 이유로 타일맵을 많이 사용
- **단위 타일 구성**: 대개 단위 타일은 게임 플레이를 구성하는 최소 단위의 오브젝트들이 위치
- **이미지 및 속성 관리**: 타일 이미지와 속성이 1:1로 대응되는 게임도 있지만 이미지와 속성을 별개로 설정하는 게임도 있다
- **오브젝트 상호작용**: 타일을 점유한 오브젝트는 상태, 방향, 충돌 등을 체크

## 타일 맵 스타일의 종류

- **직교 투영 (Orthogonal)**: 정면에서 본 격자형 타일 배치
- **등각 투영 (Isometric)**: 45도 회전된 다이아몬드형 타일
- **육각형 (Hexagonal)**: 전략 게임에서 자주 사용되는 형태

## 타일 맵 시스템

- **타일 배치**: 맵 레이아웃을 타일로 구성
- **타일 속성 설정**: 이동성, 지형, 상호작용 지정
- **타일 세트 디자인**: 경계와 패턴을 일관되게 제작
- **게임 플레이 테스트**: 충돌과 밸런스 점검

타일 맵은 작은 단위 이미지를 반복 배치하여 큰 맵을 효율적으로 구성하는 기법이다.

### 타일 맵의 장점

- RPG, RTS, 시뮬레이션 등 다양한 장르에서 활용
- 메모리 사용량을 크게 절감
- 맵 편집과 수정에 용이

### 타일이 가진 정보

지형 속성, 이동 가능 여부, 높이 값, 제어 가능 여부 등의 데이터를 포함한다.

## 타일 맵 활용 사례

스타듀밸리의 농장 시스템, 파이널 판타지 택틱스의 전투 맵, 문명 시리즈의 세계 지도 등 수많은 명작 게임들이 타일 맵 시스템을 효과적으로 활용하고 있다. 각 게임의 장르와 특성에 맞게 타일 크기, 모양, 속성을 다르게 설계한다.

## 2D 오브젝트의 구성

게임 속 캐릭터와 오브젝트가 생동감 있게 움직이는 원리

## 스프라이트

이미지 출력과 애니메이션을 관리하는 핵심 클래스이다. 각 프레임별로 이미지, 위치, 효과정보가 저장된다.

**주요 기능**
- 모든 애니메이션 오브젝트의 효과적 관리
- 이미지 재사용으로 용량 절감
- 메모리 효율성 극대화

## 스프라이트 데이터 구조

1. **이미지 데이터**: 캐릭터, 장비, 이펙트, 상태 아이콘 등 모든 시각 요소를 포함한다. 캐릭터를 기준으로 장비, 이펙트 등의 각 이미지가 부착될 좌표를 정밀하게 지정한다
2. **기준점 (Pivot)**: 시점에 따라 다르게 설정된다. 탑뷰는 좌상단, 쿼터뷰는 하단 중앙, 사이드뷰는 우하단을 주로 사용한다.
3. **애니메이션 제어**: 이미지 조합과 반전, 회전, 확대/축소, 색 변환 등의 효과로 데이터를 최소화한다. 출력 순서, 딜레이, 반복 구간을 설정하여 다양한 애니메이션을 표현한다.
4. **충돌 박스 (Hit Box)**: 공격을 받는 피격 박스와 공격을 가하는 타격 박스를 각각 정의한다.

## Skeletal Animation

**뼈대 기반 애니메이션**

계층 구조로 연결된 뼈대(Skeleton or Rig)를 이용하여 자연스러운 애니메이션을 만드는 고급 기법이다.

**작동 원리**
- 각 연결점은 위치와 방향 정보를 가짐
- 물리 엔진으로 키 프레임 간 자동 전환
- 데이터 용량 절약과 자연스러운 동작 구현

*(이미지 생략: 스켈레탈 애니메이션 뼈대 구조 예시)*

## 팔레트 시스템

**색상 변환 기법**

미술 시간에 사용하던 팔레트와 동일한 개념이다. 색상 정보만 교체하여 하나의 이미지를 다양하게 재활용할 수 있다.

**활용 사례**
- RTS 게임의 팀 색상 구분
- 스포츠 게임의 유니폼 색상
- 레벨별 몬스터 차별화
- 장비 등급 표시

*(이미지 생략: 팔레트 색상 변환 예시)*

## 아바타 시스템

아바타 시스템은 *레이어, 스프라이트, 팔레트 기술*을 종합적으로 활용한 결과물이다. 플레이어가 선택한 의상, 헤어스타일, 악세서리가 실시간으로 조합되어 표현된다. 각 파츠가 독립적으로 관리되므로 무한에 가까운 커스터마이징이 가능하다.
