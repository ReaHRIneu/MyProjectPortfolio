## 규칙

- 파일당 문서 하나, 하위 폴더 없이 평평하게 나열합니다.
- 파일 맨 위에 출처를 남깁니다:

```
- **출처**: <Notion 페이지 URL>

```

- 파일명은 영문 소문자 kebab-case로 짓습니다 (예: `physics-notes.md`).
