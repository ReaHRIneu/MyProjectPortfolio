# 라이브러리 (외부 참고자료)

Notion 등 외부 소스에서 가져온 참고 문서를 모아두는 공간입니다. 프로젝트/노트 본문이 아니라 "가져온 자료"이므로 여기서 따로 관리합니다.

## 규칙

- 출처(주제/시기)별로 하위 폴더 하나를 만들어 관련 문서를 묶습니다. 폴더명은 `<주제>(<회차>)` 형태로 짓습니다 (예: `게임기획교육자료(1)`, 다음 묶음은 `게임기획교육자료(2)`).
- 각 하위 폴더 안에는 파일당 문서 하나, 그 안에서는 하위 폴더 없이 평평하게 나열합니다.
- 각 하위 폴더에는 자체 `README.md`를 두어 그 묶음의 용도와 문서 목록(출처/가져온 날짜)을 정리합니다.
- 파일 맨 위에 출처를 남깁니다:

```
- **출처**: <Notion 페이지 URL>
- **가져온 날짜**: YYYY-MM-DD
```

- 파일명은 영문 소문자 kebab-case로 짓습니다 (예: `physics-notes.md`).
