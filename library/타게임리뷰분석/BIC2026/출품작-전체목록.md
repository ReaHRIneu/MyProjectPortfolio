# BIC 2026 출품작 전체 목록

- 조사일: 2026-08-15
- 총 326개 (숫자 시작 1개, 영어 시작 125개, 한글 시작 197개, 기타 문자 시작 3개)
- 형식: `번호. 게임명 - 개발사명` (Steam 페이지가 확인된 경우 `- [Steam](URL)` 추가)
- 홈페이지: 출품작 상세 페이지가 로그인 후에만 열람 가능해 직접 수집하지 못했고, 대신 Steam 스토어 검색 API로 제목이 정확히 일치하는 91개(28%)만 채웠습니다. 나머지는 Steam 미출시(학생작/프로토타입 다수)이거나 제목 표기가 달라 매칭되지 않은 경우입니다.
