- 조사일: 2026-08-15
- 총 326개 (숫자 시작 1개, 영어 시작 125개, 한글 시작 197개, 기타 문자 시작 3개)

- 하드웨어/장르/국가는 bicfest.org 출품작 목록 페이지에 표기된 값을 그대로 옮긴 것으로, 비어있는 경우 원본 페이지에도 정보가 기재되지 않은 항목입니다.
