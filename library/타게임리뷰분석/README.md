# 타게임 리뷰 분석

게임 행사(전시회, 쇼케이스 등)나 CBT/OBT/QA에서 직접 플레이해본 타 게임에 대한 리뷰와 분석을 정리하는 공간입니다.

**용도**: 게임 프로젝트 기획서([templates/game-design/](../../templates/game-design/) 참고) 작성 시 시장/경쟁작 분석 근거나 아이디어 참고 자료로 활용합니다.

## 작성 규칙

- 파일당 게임(또는 세션) 하나, 하위 폴더 없이 평평하게 나열합니다.
- 파일명은 `<날짜(YY-MM-DD)>-<게임명>.md` 형태로 짓습니다 (예: `26-08-09-스타필드.md`).
- 파일 맨 위에 아래 메타 정보를 남깁니다:

```
- **게임명**:
- **접한 경로**: 게임 행사 / CBT / OBT / QA 등
- **날짜**: YYYY-MM-DD
- **장르 · 플랫폼**:
```

- 본문에는 자유롭게 작성하되, 다음 항목을 포함하는 걸 권장합니다: 핵심 재미/컨셉, 장점, 단점, 아쉬웠던 점, 우리 프로젝트에 참고할 만한 점.
