# Unity / 게임 개발 프로젝트

Unity로 진행한 프로젝트의 기획 문서, 시스템 설계, 코드 스니펫, 트러블슈팅 기록을 정리하는 공간입니다. 프로젝트별로 하위 폴더(`unity/<프로젝트명>/`)를 만들어 문서를 담습니다.

새 프로젝트를 시작할 땐 [`templates/game-design/`](../../templates/game-design/)의 1차(컨셉)·2차(시스템/컨텐츠)·3차(세부 항목) 기획서 구조를 그대로 복사해서 채웁니다. 기획서 작성 시 참고할 이론/강의 자료는 [`library/게임기획교육자료(1)`](../../library/게임기획교육자료(1)/README.md)에 있습니다.
