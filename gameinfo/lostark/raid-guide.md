### 그림자 레이드

#### 세르카

- **출시**: 2026-01-07 첫 그림자 레이드
- **제한 시간**: 관문당 10분
- **1관문 취약 속성**: 없음 / **2관문 취약 속성**: 성(聖)

##### 1관문 — 세르카 말레피스 돌로리스

| 구간 | 패턴 | 대처 |
| --- | --- | --- |
| 랜덤 | 빨간 낫 | 강공격, 즉사급 피해. 나이트메어는 범위 미표시. 환영 공격 방향 반대(또는 낫을 들기 전 방향)로 회피 |
| 270~200줄 | 안전지대(가시장판+톱니) | 세로 가시 장판이 좌우 이동하며 한 곳만 안전. 톱니바퀴가 위에서 2번 내려옴(2번째는 다른 줄). 못 장판은 일직선으로 조준되므로 어글자 기준 위치 조절 |
| 240줄 | 못 저스트가드 | 4번 망치질, 매 공격마다 안전지대가 1칸씩 이동 후 4번째는 못 아래 고정. 장판이 차오를 때 타이밍 맞춰 저스트가드(모션과 무관하게 타이밍 동일) |
| 200줄 | 거대 망치 장벽 | 좌우 망치 장벽이 교대로 압착, 압착되면 즉사. 노말만 범위 표시 |
| 200~100줄 | 폭탄 빙고 | 맵이 6x6로 축소, 폭탄 4~5개 랜덤 배치. 터지면 해당 가로/세로 전체 피해. 노말만 폭발 범위 표시 |
| 100줄 | 안전지대(개인 폭탄) | 4명 모두 가시 폭탄 지정, 맵 중앙부터 가시 장판 순차 확산. 약 10초간 가시 없는 발판 유지하다 장판이 초록색일 때 진입. 시간 초과 시 즉사 |
| 100줄 이후 | 화염 메이든 빙고 | 맵이 4x4로 추가 축소, 메이든이 일직선 불 공격(노말/하드 6개, 나이트메어 2개 메이든 → 안전 구역 차이). 노말만 범위 표시 |

- **대난투**: 무력화 게이지 완전 소진 시 발동. 10초 내 게이지를 채워 협동 저스트가드, 성공도에 따라 Good(+2초)/Great(+4초)/Excellent(+6초)/Perfect(+10초) 추가시간 획득

##### 2관문 — 코르부스 툴 라크

- **간파 시스템**: 화면 암전 후 보스 눈이 붉게 빛나면 스페이스로 이동기 사용(나이트메어는 눈빛 없이 타이밍만으로 판단). 실패 시 **봉인**(최대 HP 50%/실드 50% 감소, 30초 지속) + **얽매임**(중첩 시 즉사) 디버프

| 구간 | 패턴 | 대처 |
| --- | --- | --- |
| 285줄 | 첫 간파 | 내려찍기 회피(스페이스 간파) → 그림자가 날개 펄럭이는 방향 반대로 회피 |
| 285~240줄 | 용오름 간파 | 회전 후 내려찍기 회피 필요, 이후 부채꼴 공격 |
| 285~240줄 | 할퀴기 카운터 간파 | 앞으로 할퀴기 회피 후, 뒤로 할퀼 때 카운터 |
| 240줄 | 진짜 찾기 | 실로 둘러진 원형 공간에서 4방향 그림자 중 진짜(기를 모으는 쪽)만 저스트가드, 가짜는 쪼기만 함. 성공 후 외부에서 가짜 방해 회피하며 무력화 (일명 "통곡의 벽") |
| 190줄 | 연속 저스트가드 | 2번 저스트가드 → 9번 찌르기 → 2번 내려찍기(2번째에 카운터) → 마지막 내려찍기 저스트가드. 전 과정 성공 시 파열 디버프 4회 획득 |
| 190~120줄 | 반격 간파 | 보스 공격 시 반격 발동, 3번 모션 중 파란색에만 카운터 |
| 190~120줄 | 웅덩이 간파 | 칼 내려꽂기 회피 후 발도 자세에 카운터 |
| 120줄 | 진짜 찾기 2 | 30초 내 8방향 중 진짜(밝은 갑주) 찾아 딜링 게이지 완성. 10초마다 전원에게 장판 생성되어 파동 피해, 가짜 공격 시 즉시 파동 확산 |
| 60줄 | 장판 무력화 간파 | 내려찍기 스페이스 간파 → 삼각형 검기 장판 피하며 무력화 진행(페이즈 마무리) |

- **즉사 주의**: 아이언메이든(저스트가드 실패 시 전멸), 뿌리 속박/목둔 패턴(무력화 실패 시 즉사)
- **대난투**: 각 단계마다 저스트가드 2회(1번째는 느린 타이밍, 2번째는 빠른 타이밍, 1번 성공해야 2번째 진행 가능)

##### 매칭 모드 특이사항

- 무제한 부활 가능(깃털/크리스탈 소모), 광폭화 시 보스 체력 회복
- 1인 플레이 시 패턴 약화 + 전조 표시 추가, 대난투는 저스트가드 1회만 수행
