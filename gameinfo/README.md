# Game Info

플레이한 게임의 공략/팁을 정리하는 공간입니다.

## 작성 규칙

- 게임별로 하위 폴더 하나를 만들어 관련 문서를 묶습니다.
- 폴더명·파일명은 모두 영문 kebab-case로 짓습니다 (예: `elden-ring/`).
- 하위 폴더 안에서는 주제별로 파일을 나눕니다 (예: `boss-guide.md`, `item-guide.md`, `walkthrough.md`).
- 각 하위 폴더에는 자체 `README.md`를 두어 게임 정보와 파일 목록을 정리합니다.
- 파일 맨 위에 아래 메타 정보를 남깁니다:

```
- **게임명**:
- **플랫폼**:
- **작성일**: YYYY-MM-DD
```
